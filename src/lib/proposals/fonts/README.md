# Proposal fonts

Static TTF instances of **Inter** (400/500/600/700, by Rasmus Andersson) and **Outfit** (500/600/700, by
Rodrigo Fuenzalida), downloaded from Google Fonts. Both are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling and embedding them in documents. Outfit and Inter
are the typefaces used on getsecure.co.nz.

TTF (not WOFF) is required: the PDF renderer drops page-number text set in WOFF fonts.
